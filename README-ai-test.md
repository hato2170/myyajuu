# AIチャット試作品の起動方法

## 必要条件

- WebGPU対応ブラウザーと対応GPU
- 初回にモデル一式（目安約300 MB）を取得できるインターネット接続
- モデル用の空き保存容量と実行時メモリ
- HTTPSまたはlocalhostでの配信（`file://` 直開きはES Modulesやブラウザー機能の制限で動かない場合があります）

## 起動

1. プロジェクトのルートをローカルWebサーバーまたはHTTPS対応の静的ホスティングで配信します。
2. `ai-test.html` を開きます。例: `http://localhost:8000/ai-test.html`。
3. 「モデルを読み込む」を押します。初回はWebLLM本体・モデルファイルを外部の公開配布元から取得します。AI推論リクエストは外部APIへ送られず、端末内で行われます。
4. 読み込み完了後、日本語で送信して応答を確認します。再読み込み後も同一ブラウザー・同一サイトの保存領域が残っていれば履歴を復元します。

## 注意

- この試作品はSNSの認証、Firestore、外部AI API、APIキー、課金機能を使いません。
- 履歴はブラウザーの`localStorage`に保存され、端末・ブラウザー単位です。ブラウザーのサイトデータ削除で消去されます。
- 初回ダウンロード容量は概算で、WebLLM本体、モデル構成、キャッシュなどにより実通信量・必要容量が異なります。
- iPhone SafariはOS・機種・メモリ・WebGPU実装の差があるため、WebGPU検出表示だけでは実行成功を保証しません。実機で確認してください。
- この環境からブラウザーでの実行・ビルド確認は行っていません。
